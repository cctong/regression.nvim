==============================================================================
1. Introduction                                      *regression-introduction*

regression.nvim records a known-good Neovim snapshot and compares the current
state with it. Snapshots include Neovim version, adapter status, startup time,
errors, active LSP clients, health messages, and plugin revisions.

lazy.nvim is the only plugin-manager adapter in version 0.1.

==============================================================================
2. Setup                                                    *regression-setup*

Call setup after lazy.nvim has been configured: >lua

  require("regression").setup({
    profile = "default",
    startup = {
      enabled = true,
      percent_threshold = 0.25,
      absolute_threshold_ms = 20,
    },
    health = { enabled = true },
    bisect = { timeout_ms = 60000, settle_ms = 1000 },
  })
<

The baseline is stored under stdpath("state")/regression.nvim by default.

==============================================================================
3. Commands                                              *regression-commands*

                                                        *:NvimBaseline*
:NvimBaseline
        Capture the current state as known-good. Refuses to overwrite an
        existing baseline.

                                                       *:NvimBaseline!*
:NvimBaseline!
        Replace the existing baseline.

                                                      *:NvimRegression*
:NvimRegression
        Capture the current state, compare it with the baseline, and open the
        report in a scratch split. Press |q| to close the report.

                                                          *:NvimBisect*
:NvimBisect
        Binary-search changed lazy.nvim plugins using headless probes. See
        |regression-bisection|.

==============================================================================
4. Bisection                                            *regression-bisection*

Bisection temporarily checks plugin repositories out at revisions recorded in
the baseline. It refuses dirty repositories, verifies baseline revisions, and
restores current revisions when it finishes or encounters an error.

Version 0.1 searches the set of changed plugins and assumes a single primary
culprit. It does not search commits within an individual plugin. Do not run
lazy.nvim updates at the same time.
